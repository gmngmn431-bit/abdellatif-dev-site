## 1. إنشاء مشروع Supabase (مجاني — 5 دقائق)

1. ادخل إلى https://supabase.com وسجّل الدخول (أو أنشئ حساباً مجانياً).
2. اضغط **New project**، اختر اسماً (مثلاً `abdellatif-dev`)، وكلمة سر قوية لقاعدة البيانات، واختر أقرب منطقة (مثلاً Frankfurt).
3. انتظر حتى يُنشأ المشروع (دقيقة أو دقيقتان).

## 2. إنشاء جداول قاعدة البيانات

1. في لوحة Supabase، افتح **SQL Editor** من القائمة الجانبية.
2. اضغط **New query**.
3. افتح ملف `schema.sql` من هذا المشروع، انسخ محتواه كاملاً والصقه في المحرر.
4. اضغط **Run**. إذا ظهرت رسالة نجاح فالجداول جاهزة.
   - الملف آمن عند إعادة التشغيل (يستعمل `IF NOT EXISTS`) — يمكنك تشغيله مرة أخرى دون مشاكل.
   - ما الذي يُنشئه؟ جداول `profiles` و `games` و `apps` و `projects` و `news` و `site_settings`، دوال عداد التحميلات، قواعد الأمان RLS، وحاويات التخزين `project-images` و `screenshots`.
   - **البيانات الأولية الوحيدة:** مشروع «لعبة الكارطة المغربية» (قيد التطوير، بلا رابط تحميل) + إعدادات Hero/About + رابط فيسبوك الوحيد المؤكد. جداول الألعاب والتطبيقات والأخبار تبدأ فارغة — تظهر بحالات فارغة جميلة حتى تضيف محتوى من لوحة الإدارة.

## 3. إنشاء حساب الأدمن

1. في Supabase، افتح **Authentication** > **Users** > **Add user** > **Create new user**.
2. أدخل بريدك الإلكتروني وكلمة سر قوية، وفعّل **Auto Confirm User**، ثم اضغط **Create user**.
3. انسخ الـ **UUID** الخاص بالمستخدم الجديد (اضغط عليه لعرض التفاصيل).
4. افتح **Table Editor** > جدول `profiles` > **Insert** > **Insert row**، وأدخل:
   - `id`: الصق الـ UUID المنسوخ
   - `email`: نفس البريد الإلكتروني
   - `role`: `admin`
5. احفظ. هذا الحساب هو الوحيد الذي يستطيع الدخول إلى لوحة الإدارة.

## 4. ربط الموقع بـ Supabase

1. في Supabase، افتح **Settings** (أيقونة الترس) > **API**.
2. انسخ **Project URL** و **anon public key** (وليس `service_role` أبداً — لا تضعه في الكود).
3. افتح ملف `supabase-client.js` وبدّل القيمتين:
   ```js
   const SUPABASE_URL = "https://YOUR-PROJECT.supabase.co";   // ← ضع Project URL هنا
   const SUPABASE_ANON_KEY = "YOUR-ANON-KEY";                  // ← ضع anon key هنا
   ```
4. احفظ الملف. الموقع يكتشف تلقائياً إذا لم تُضبط القيم ويعرض تنبيه إعداد بدل الفشل الصامت.

## 5. النشر على GitHub Pages (مجاني)

1. أنشئ حساب GitHub (إن لم يكن لديك) وريبو جديداً، مثلاً `abdellatif-dev-site` (عام Public).
2. ارفع كل ملفات هذا المشروع إلى الريبو (اسحبها من جهازك أو عبر Git).
3. في الريبو: **Settings** > **Pages** > **Build and deployment** > Source: **Deploy from a branch** > Branch: **main** > Folder: **/ (root)** > **Save**.
4. انتظر دقيقة — موقعك يصبح متاحاً على: `https://اسم-حسابك.github.io/abdellatif-dev-site/`
5. لوحة الإدارة على: `https://اسم-حسابك.github.io/abdellatif-dev-site/admin.html`

## 6. الدخول إلى لوحة الإدارة

1. افتح رابط `admin.html`، وأدخل بريد الأدمن وكلمة السر (من الخطوة 3).
2. إذا ظهر «هذا الحساب ليس أدمن» فهذا يعني أن سطر `profiles` غير مضاف أو أن `role` ليس `admin` — راجع الخطوة 3.
3. من اللوحة يمكنك:
   - **الألعاب / التطبيقات:** إضافة، تعديل، حذف، نشر/مسودة، معاينة. كل عنصر: اسم، تصنيف، وصف مختصر وكامل، مميزات، غلاف (رفع أو رابط)، لقطات متعددة، إصدار، حالة (متاحة / قيد التطوير / قريباً)، رابط تحميل خارجي (MediaFire...)، متطلبات تشغيل.
   - **المشاريع قيد التطوير:** اسم، صورة، وصف، نسبة تقدم % (اختياري)، آخر مستجد، الحالة.
   - **الأخبار:** عنوان، صورة، تصنيف، محتوى، رابط خارجي، تاريخ النشر.
   - **الإعدادات:** نصوص Hero، معلومات «عن المطور»، التقنيات، وروابط التواصل الاجتماعي (اترك أي حقل فارغاً إذا لم يكن لديك الحساب — لن يظهر).
4. **كل تغيير يظهر في الموقع مباشرة** دون إعادة رفع الملفات — لأن المحتوى يُجلب من قاعدة البيانات عند كل زيارة.
5. اللوحة تعمل من الهاتف أيضاً (جداول وفورم متجاوبة).

## ملاحظات مهمة

- **روابط التحميل:** لا توجد أي روابط وهمية في الموقع. إذا لم تضف رابط تحميل للعبة/تطبيق، يظهر زر «قريباً» معطّلاً بدل رابط ميت. عند إضافة رابط يظهر عداد 7 ثوانٍ ثم زر التحميل، وتُحسب نقرة التحميل في قاعدة البيانات.
- **الصور:** الصور المرفوعة من لوحة الإدارة تُحفظ بشكل دائم في Supabase Storage (حاويتا `project-images` و `screenshots`)، وليست صوراً مؤقتة.
- **الأمان:** الزوار يرون المحتوى المنشور فقط (RLS). الإدارة محمية بتسجيل الدخول + فحص `profiles.role = 'admin'` في كل عملية. لا توجد كلمات سر أو مفاتيح سرية في كود الواجهة — مفتاح `anon` وحده موجود، وهو مفتاح عام آمن بوجود RLS.
- **صفحات قابلة للمشاركة:** كل لعبة/تطبيق/خبر له رابط خاص (مثلاً `#/game/…`) يمكن مشاركته مباشرة.
- **SEO:** عنوان ووصف ووسوم Open Graph و `theme-color` وأيقونة مضبوطة في `index.html`.
